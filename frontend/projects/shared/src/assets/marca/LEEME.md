# Identidad visual

`logo-udh.png` es el logotipo oficial de la Universidad de Huánuco, descargado sin cambios el 17/11/2026 de <https://www.udh.edu.pe/img/logo.png> (PNG, 273 × 63 px). No se modifica, recorta ni redibuja.

- Si la Oficina de Imagen Institucional entrega una versión de mayor resolución (SVG o PNG a 2x), reemplace este archivo conservando el nombre.
- El logotipo tiene letras grafito: úselo solo sobre fondo blanco o muy claro.
- Si el archivo falta, el componente `<udh-marca>` muestra el nombre de la universidad en texto.

Paleta derivada del logotipo (definida en `projects/shared/src/styles/_base.scss`):

| Color | Hex | Uso |
|---|---|---|
| Verde institucional | `#30B8A0` | Detalles de marca: barras, subrayados, íconos |
| Verde oscuro | `#0D7A6A` | Botones y enlaces (contraste AA con blanco) |
| Grafito | `#2B2B2B` | Barra superior, pie, títulos |
| Oro del escudo | `#F8C020` | Acentos puntuales sobre fondo oscuro |
