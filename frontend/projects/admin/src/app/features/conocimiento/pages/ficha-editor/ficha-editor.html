Ciclo de publicación

  1. El editor guarda el borrador.
  2. Lo envía a revisión: el sistema valida el contrato.
  3. Un revisor distinto aprueba o rechaza con observaciones.
  4. Al aprobar se reindexa y se corre una prueba de humo con el golden set.
