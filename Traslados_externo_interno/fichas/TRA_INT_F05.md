# TRA_INT_F05 — Registro de Convalidación Interna

## Descripción

Después de presentar los documentos, el estudiante registra la solicitud en el módulo de Convalidaciones del Sistema Login UDH.

## Requisitos

- Documentación presentada según la fase 4.
- Acceso al Sistema Login UDH.

## Pasos

1. Ingresar nuevamente al Sistema Login UDH.
2. Abrir Convalidaciones.
3. Seleccionar Interno.
4. Pagar S/ 5.00 por la solicitud de convalidación interna y registrar la solicitud.

## Pago

- S/ 5.00 por solicitud de convalidación interna (solicitud_convalidacion).

## Plazo

No indicado.

## Responsable

Estudiante; Sistema Login UDH como canal; Coordinación Académica recibe la solicitud para evaluación.

## Enviar a

Login UDH → Convalidaciones → Interno.

## Resultado de la etapa

Solicitud de convalidación interna registrada.

[TRA_INT_F06](TRA_INT_F06.md)

## Observaciones

Seleccionar Interno, no Externo. No se documenta un medio específico de pago ni un mecanismo de consulta del estado.
